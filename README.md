# SafiStay — Landing Page

SafiStay is a fictional Kenyan hospitality/travel landing-page concept created as a responsive front-end project.

**Tagline:** Stay somewhere worth remembering.

## What it demonstrates
- Responsive design and mobile-first breakpoints
- Semantic HTML5
- Modern CSS layout
- Vanilla JavaScript
- Mobile hamburger navigation
- Smooth anchor scrolling
- Scroll-reveal animations
- Keyboard focus states and reduced-motion support
- Featured stays and destination cards
- Testimonials
- Contact and social links
- Organized project structure and README

## Tech stack
HTML5 • CSS3 • Vanilla JavaScript • Google Fonts • Unsplash demo imagery

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## GitHub Pages
1. Public repository named `landing-page-project`.
2. Upload the project files.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, then `main` and `/root`.
5. Save and wait for the public URL.

## Demo content
Property names, testimonials, contact details, and SafiStay social destinations are fictional/demo content. Replace them with real client information if this concept is adapted for a real hospitality business.

The photos use Unsplash demo URLs and can be replaced with properly licensed client/brand photography.
